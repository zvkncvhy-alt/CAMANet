# Evidence-Chain CAMANet Fork

This repository is a research fork of the public CAMANet codebase for radiology report generation. The CAM-guided modules from CAMANet are kept in the tree for backward compatibility, but the default training scripts now use an evidence-chain architecture instead of class activation map guided foreground/background learning.

## Method Overview

The evidence-chain model replaces CAM-guided supervision with three coupled modules:

1. **Anatomy-aware Evidence Tokenization (AET)** converts unordered visual patch features into a compact set of learnable anatomy evidence tokens.
2. **Disease-state Evidence Refinement (DSER)** derives disease-specific evidence tokens from the anatomy evidence tokens and predicts disease labels for multi-task supervision.
3. **Evidence Coverage Constrained Decoding (ECCD)** uses decoder cross-attention to encourage coverage of positive disease evidence while suppressing attention to negative disease evidence.

The resulting evidence flow is:

```text
image patches -> anatomy evidence -> disease-state evidence -> coverage-constrained report decoder
```

The design is end-to-end and does not require retrieval augmentation, offline exemplar files, or precomputed report-memory indices.

## Prerequisites

The following packages are required to run the scripts:
- Python >= 3.6
- PyTorch = 1.6
- Torchvision
- Pycocoevalcap

You can create the environment via conda:

```bash
conda env create --name [env_name] --file env.yml
```

## Datasets

The code supports IU X-Ray and MIMIC-CXR.

For `IU X-Ray`, download the dataset from the Open-i/NLM website.
For `MIMIC-CXR`, download the dataset from PhysioNet.

After downloading the datasets, put them in the directory `data`.

## Labels

The evidence-chain model uses the existing multi-label supervision interface. You may use labels generated by CheXbert or compatible 14-label files in the same format as the original project label files.

## Train on IU X-Ray

Run:

```bash
bash run_iu.sh
```

## Train on MIMIC-CXR

Run:

```bash
bash run_mimic.sh
```

## Test on MIMIC-CXR

Run:

```bash
bash test_mimic.sh
```

## Implementation Notes

- `modules/evidence_chain.py` implements AET and DSER.
- `modules/evidence_losses.py` implements ECCD coverage regularization.
- `models/model.py` routes `--evidence_chain` runs through the new evidence modules and bypasses CAM-guided foreground/background learning.
- `modules/trainer.py` adds disease classification and evidence coverage losses during training.
